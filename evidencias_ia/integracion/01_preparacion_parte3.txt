  What the tool does (mcp/server.py):
  - It downloads the series through the same internal function as serie, so the
    periods and source URL are identical.
  - It saves the data to salidas/bcrp_<codigo>.csv, with columns for period,
    value, code, name, unit and source.
  - It saves a line chart to figuras/bcrp_<codigo>.png in the ENAHO style: dark
    blue line, bold findings title, a subtitle with the series name, unit,
    frequency and period, and the note "Fuente: BCRP, serie <codigo>, <url>".
    The last value is labelled on the line.
  - It returns both file paths, the code, the period actually covered (first and
    last data point), the number of points and the source.

  No hand-typed figures:
  - titulo is optional. If you leave it empty, the title is built from the first
    and last values in the downloaded data.
  - The docstring tells the model to take any figures for the title from
    resumen.
  - The unit comes from the BCRP catalogue. Its unit column is almost always
    empty, so in practice the unit is read from the bracketed part of the series
    name (e.g. "var% 12 meses", "S/ por US$").
  - If any periods had no data, the note says how many were skipped.

  I tested it with the 12-month inflation series (PN01273PM, monthly) and the
  daily interbank exchange rate (PD04638PD), and both charts came out correctly.
  I deleted those test images and CSVs before committing, so you can generate
  the real ones in Part 3.
